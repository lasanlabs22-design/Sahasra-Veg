# Sahasra Pure Veg

Website for Sahasra Pure Veg, a pure vegetarian restaurant in Chittoor, Andhra Pradesh.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Commands

- `npm run build`: production build
- `npm run start`: serve the production build
- `npm run lint`: lint

## Where things live

- `src/lib/site.ts`: phone, address, social links, GSTIN, FSSAI. Edit contact details here.
- `src/lib/photos.ts`: every photo with its alt text and licence credit.
- `src/components/home/`: one file per home page section.
- `src/app/privacy-policy`, `src/app/terms-and-conditions`, `src/app/photo-credits`: legal pages.
